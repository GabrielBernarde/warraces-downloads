# warraces-downloads
Instalador e atualizações de teste do WarRaces para Windows.
## Aviso sobre bloqueio no Windows

As builds de teste atuais ainda nao possuem assinatura de fornecedor Authenticode. O Controle Inteligente de Aplicativos do Windows pode bloquear o jogo com a mensagem de que nao foi possivel verificar o fornecedor. Esse aviso, por si so, nao e uma deteccao de virus e tambem nao comprova a seguranca do arquivo.

A assinatura usada pelo launcher verifica a integridade das atualizacoes; ela nao substitui o certificado de assinatura de codigo exigido para identificar o fornecedor no Windows. Atualizar para a versao mais recente nao garante eliminar esse bloqueio enquanto a assinatura reconhecida nao estiver disponivel.

A etapa de assinatura esta sendo preparada, mas ainda depende de certificado reconhecido e validacao. Nao desative o antivirus ou o Controle Inteligente de Aplicativos para executar o jogo. Se ocorrer esse bloqueio, aguarde uma distribuicao assinada e validada.

Este download e para Windows. Nao representa suporte a macOS ou Linux.

[Informacoes da Microsoft sobre assinatura para Smart App Control](https://learn.microsoft.com/en-us/windows/apps/develop/smart-app-control/code-signing-for-smart-app-control)
